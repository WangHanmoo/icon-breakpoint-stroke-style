二、像素反测：这套图标的设计 Token（24px 基准）

复测修正（第二版）：用亚像素墨量法逐图标标定后确认——全组线宽严格统一为 2（物理实测 2.51px，截图按 125% 渲染 → ÷1.25 = 2.01）；容器中心线 20×20（外径 22）、圆角 5、globe 圆 r10，全部吻合 24 栅格。内部短杠与主线等粗——初版"短杠配重 2.5"是抗锯齿造成的误读，已废除。plus 图标（物理 2.81）是原图自身唯一偏差项，不继承。

三、风格签名：断点（Breakpoint）的五条规则

这套图标最独特的识别点不是圆角，而是"该连的地方故意不连"。所有轮廓在以下五种位置断开：

① 内细节靠近处断

文件折角、内容杠从不与外框相接（左：连续错误；右：断开正确示意）——凡内部元素距轮廓 ≤6px，轮廓在此处让位断开 2–3px。

② 拐角即断点

scan 图标：完整方框被拆成四个"短臂圆弧"，臂长仅 4px。直角不硬画，用圆弧 + 断口表达"取景/扫描"的开放感。

③ 封闭只留给容器主形

terminal / plus：外框是封闭圆角矩形；而 stack 的层叠用开放式 chevron（不闭合、不回笔），封闭形 = "框住的东西"，开放形 = "动态/过程"。

④ 内部细节一律短杠

robot 眼睛、terminal 命令杠、file 正文行：内部元素永远是 3–6px 的独立短杠，绝不拉通、绝不顶边；厚度与主线同为 2（复测确认，勿加粗）。

⑤ 斜线与圆做光学补正。45° 斜笔画在像素栅格上天然显细，实测中斜向读数普遍为 3px（水平 2px）；圆形（globe）允许 ±1–2px 出格。落到 SVG 上即：斜线 stroke 可 +0.25~0.5，或整体对 0.5px 栅格取半。

四、用这套 Token 重绘「摘要」icon

收束核 · 断点风格版

三条会话输入线（开放笔画，端点同落 x=6 轴、起点同落 x=2 轴）→ 圆角容器核 12×12（封闭 = 结果）→ 核内一条 4px 短杠（蒸馏出的要点）。笔画统一线宽 2；全部间隙 ∈ {2,3,4,6}，线-核、杠-壁四处间隙全部 = 2。

同一图标的降级与状态

激活态走"核实心 + 短杠反白"；16px 降级时三条输入线减为两条，线宽保持 2 不变，只减元素不减线宽。

五、可直接抄的参数（SVG / CSS 变量）

:root {
  --icon-grid: 24;               /* 画布 24×24，内容安全区 22×22 */
  --icon-stroke: 2;              /* @16px → 1.75，@32px → 2.5 */
  --icon-cap: round;
  --icon-join: round;
  --icon-container-rx: 5;        /* 容器 path 圆角 ≈25% 边长（角部拟合 5.0）——半径阶梯的唯一例外 */
  --icon-radius-ladder: 2 1 2.41; /* 90° 圆角阶梯：形 ≥8 → 2；<8 → 1；直角相交对角线 → 2.41（1+√2） */
  --icon-canvas-margin: 1;       /* 笔画与画布边缘 ≥1（描边外缘落在 1–23） */
  --icon-gap-test: 2px-circle;   /* 2px 圆内切测试：直径 2 的圆放得进间隙即合格 */
  --icon-diagonal: on-grid;      /* 对角线贴像素网格，禁离格斜线（低密度屏发虚显宽） */
  --icon-curve: arc/quad-first;  /* 简单弧/二次优先；三次贝塞尔控制点对齐、数量最少 */
  --icon-bracket-r: 4;           /* 取景角弧半径，臂长 4 */
  --icon-gap-scale: 2 3 4 6;     /* 间隙模数（=1×/1.5×/2×/3× 线宽），禁用其他值 */
  --icon-gap-break: 2;           /* 轮廓断点：1–1.5× 线宽 */
  --icon-gap-element: 2;         /* 相邻构件最小净间隙 ≥2；主次分层用 4–6 */
  --icon-dash-min: 4;            /* 内部短杠最短 4，最长 6 */
  --icon-dash-weight: 2;         /* 内部短杠与主线等粗，勿加粗（复测修正） */
  --icon-overshoot: 1.5;         /* 圆形/出格元素光学补正 ≤2 */
  --icon-color: #96969B;         /* 默认 */
  --icon-color-active: #171718;  /* 激活 */
  --icon-card-bg: #FFFFFF;       /* 激活卡片 */
  --icon-card-radius: 12px;      /* @44–48 卡片，≈25% */
  --icon-card-border: 1px solid rgba(23, 23, 24, .06);
  --icon-card-shadow: 0 1px 3px rgba(23, 23, 24, .08);
  --icon-palette: #96969B #171718 #F4F5FC;  /* 色值锁定：唯一合法色板；加新色只能改这里，全组生效 */
  --icon-view-angle: 0deg;       /* 全组正视；禁等轴测 / 透视 / 3-4 侧视 */
  --icon-motif-mode: implicit;   /* 母题档位：implicit 隐性（默认）/ marked 标记 / emphasized 强调——画前与用户确认 */
}

验收口诀：线 2 圆头；框圆角五分一；杠短四到六；见细就断开，断口一倍半；间隙只用二三四六；斜线不加磅，圆形可出格；正视画、色锁死、记号同形同位；圆角走阶梯（二一又点四一），多线交汇不倒角。

八、验收清单（24 条，缺一不打回）

  • 线宽 = 2（@24），全部 round cap + round join
  • 封闭容器圆角 = 5（≈25% 边长），小容器按同比例
  • 任意两个独立元素不接触，净间隙 ≥2；连通域数与声明元素数一致
  • 全部间隙落在模数 {2,3,4,6}，同一图标内尽量同档
  • 内部细节是独立短杠，长度 3–6，不顶边、不拉通
  • 内部短杠与主线等粗 2，任何方向（含斜线）都不加粗
  • 成组构件同尺寸、同圆角、同间距（同构重复）
  • 横竖笔画共轴、成组端点落在同一轴上，斜线端点落在网格交叉点
  • 主形落在 20×20 安全区内，描边外缘不出 keyline（1–23）
  • 几何中心偏移 ≤0.6，墨量在 9–32% 带内（自动验收会给读数）
  • 与同组图标视觉重量一致（墨量相当，不喧宾夺主）
  • 16px / 20px 缩放后主形仍可辨认（必要时减元素，不缩线宽）
  • 颜色只用 token：默认 #96969B、激活 #171718，不使用填充色
  • SVG 用 stroke 不用 fill；无内联样式、无 transform 缩放依赖
  • 语义经符号化阶梯定位：画关系不画东西，构件来自构件库
  • 与同组 8 个图标并排不撞语义（做一次邻位混淆检查）
  • 全组正视：无等轴测、无透视、无 3-4 侧视；同一物体在组内视角恒定
  • 色值锁定：SVG 内只出现 currentColor / none / 锁定色板；stroke-width 属性全部 =2
  • 母题一致（若启用标记/强调档）：全组同形同尺寸同位、覆盖率 100%，且母题来自构件库
  • 繁简一致：同形类图标墨量极差 ≤5 个百分点；降级全组走同一张矩阵
  • 半径阶梯：90° 圆角 ≥8 形 → 2、<8 形 → 1、直角相交对角线 → 2.41（1+√2）；rx 全部落在白名单 {1,2,2.41,2.5,3,5}
  • 多线交汇保持棱角：≥3 条线相交的拐角不倒圆角（缩放红线）
  • 对角线贴像素网格；曲线用简单弧/二次曲线，三次贝塞尔控制点对齐且数量最少；描边居中于路径
  • 命名与随行：kebab-case、按所见命名（非用途）、同组 <group>-<variant>、版本按视觉差异命名（禁纯数字）、多元素按视觉位置排序（重叠前到后，不重叠上到下左到右）、元数据文件与 SVG 同目录随行

十二、构成五法 + 腔体约束 + 符号化阶梯（建筑感从哪来）

构成五法

  1. 模数制：关键坐标落在 0.5 网格，构件尺寸取整模数（2/4/6/8/12/20）；坐标出现 3.7、9.3 一律打回。
  2. 同轴对齐：横竖笔画共用同一 x/y 轴，成组端点落在同一条轴上（收束核三线同落 x=6、起点同落 x=2）；斜线两端各落在一个网格交叉点上。
  3. 同构重复：同层构件同尺寸、同圆角、同间距——节点阵列是两个 6×6 rx2，不是一大一小两个异形。重复产生韵律，韵律产生秩序感。
  4. 结构分层，不靠线宽分层：主形（容器，20 级）→ 次级构件（短杠/V 形/勾，4–8 级）→ 节点（≤6 级）。层级靠尺寸与闭合状态表达，线宽永远 2。
  5. 负形即版式：留白也是矩形，腔体至少一边取整模数；复杂性来自构件层数与重复，不来自塞满（墨量带 9–32%）。

符号化阶梯

L0 具象（禁止）：画物体本身（有脸有耳的机器人）。L1 提炼（仅必要时）：保留一个几何化识别特征（文件折角、终端光标）。L2 关系符号（默认）：不画东西画关系——汇聚、收束、嵌套、阵列、层级。判据三问：画的是"东西"还是"关系"？去掉某笔还成立吗（成立即装饰，删）？构件是不是构件库里的现成货？构件库只许五种：圆角容器、短杠、节点方块/圆、V 形收口、chevron。新图标 = 旧构件的新组合，这就是"符号化"的机制。

自动验收（check-style.py）

python3 check-style.py "examples/*.svg" --scale 12

像素实测，不靠肉眼：粘连/断裂（连通域计数 vs 声明元素数，FAIL）、线宽（8 方向行程长度取最小再取中位，2±0.2，FAIL）、间隙（精确欧氏距离变换，≥2 且落模数；手测判据 = 2px 圆内切）、边距（笔画离画布边缘 ≥1，WARN）、墨量（9–32%，WARN）、居中（偏移 ≤0.6，WARN）、色值锁定（静态扫描 hex/rgb()/CSS 颜色名，只允许 currentColor、none 与锁定色板，FAIL）、线宽属性（静态扫描全部 stroke-width，必须=2，FAIL）、圆角白名单（静态扫描全部 rx，只允许 {1,2,2.41,2.5,3,5}，FAIL）、文件名规范（kebab-case + 纯数字版本段，WARN）、元数据随行（同目录有元数据约定时缺文件，WARN）。测量三坑：内切半径在 round join 处虚高（改用行程法）；chamfer(3,4) 斜线方向误差 ~8%（改用精确 EDT）；间隙读数含 1px 像素中心系统偏置。

十三、三同铁律（同画法 · 同颜色 · 同记号）

单个图标合格只是及格线，一组图标像一家人才是验收目标。三同是家族感的机制。

一、同画法（linear：单色描边 · 统一线宽 · 圆角收笔）

  • 单色描边：整组一支笔——currentColor 或锁定色板里的一个色值；无渐变、无双色、无填充色块。
  • 统一线宽：任何方向、任何层级都是 2（含短杠与斜线）。
  • 圆角收笔：round cap/join；容器圆角 ≈25% 边长；拐角即断点，不画方角。
  • 同一网格：全部 24px 栅格、0.5px 落点、keyline 1–23。
  • 同一视角：全组正视 0°。禁等轴测、禁透视、禁 3-4 侧视；同一物体永远同一视角（时钟永远正视、文件永远正视带折角）。视角漂移是家族感瓦解的头号原因，且比颜色漂移更隐蔽。
  • 同一繁简：同形类图标墨量同带（开放型 9–13%、容器型 23–30%，组内极差 ≤5 个百分点）；降级全组走同一张尺寸降级矩阵，不许有的砍细节、有的保留。

二、同颜色（色值锁定，防"越画越艳、越画越偏"）

  • 色板锁死：默认 #96969B / 激活 #171718 / 底 #F4F5FC，写死在 token 表，逐批不许微调。
  • SVG 里只允许 currentColor、none、锁定色板内的色值；色板外的任何 hex / rgb() / CSS 颜色名 = 打回。
  • 加新颜色的唯一通道：token 表加一行，然后全组统一生效；禁止单枚图标局部定义新色。
  • 机器把关：check-style.py 静态扫描色值，不在色板即 FAIL；--palette 可换色板（如深色主题）。

三、同记号（母题 motif：让图标拥有身份）

档位规则适用
L0 隐性（默认）母题只在语义需要处自然出现，不额外强调。本套天然母题是断点缺口——它本来就是签名通用工具型图标组
L1 标记母题出现在组内每一枚图标上（恰好 1 处），位置相对固定（收笔端 / 右下），同形同尺寸同圆角，从构件库取品牌图标组、要被一眼认出的产品图标
L2 强调母题允许唯一一处特权：用激活色 #171718 或尺寸升一档——全组唯一被允许的强调手段母题即品牌符号

硬规则：① 母题永远从构件库取，不许为母题发明新形状——母题是"复用最多的构件"，不是新构件；② 组内同形同尺寸同圆角，L1/L2 档覆盖率 100%（忽有忽无 = 打回）；③ L1 档位置相对固定但让位于防粘连、腔体、居中——宁可换位置不许破坏构图；④ 一组只用一个母题，两个母题 = 没有母题。

十四、命名与交付规范

项规则
文件命名小写 kebab-case：^[a-z0-9]+(-[a-z0-9]+)*\.svg$，例 arrow-up-0-1.svg
命名语义描述图标所画的东西，不描述人们怎么用它——画 arrow-down-tray，不画 export
组与变体同组用 <group>-<variant>，组名在前变体在后：badge-plus & badge-check，组是 badge
版本命名按视觉差异命名，禁纯数字区分——写 chevron-left-collapse，不写 chevron-left-2
多元素排序按视觉位置命名：元素重叠 → 从前到后；不重叠 → 英语阅读顺序（从上到下，再从左到右）
元数据随行每个图标的元数据文件与对应 SVG 同放在 icons 目录，一一随行
变体复用做变体保留基本图标的几何（坐标/圆角/断点），附加件位置与尺寸跨变体一致——除非新想法本身要求改动
SVG 结构viewBox="0 0 24 24"，单一 <g stroke-width="2" fill="none" stroke-linecap="round" stroke-linejoin="round">，颜色用 currentColor 便于主题化；首行注释声明元素数：<!-- elements: 5 | 摘要·收束核 | 一句话构成 -->（自动验收靠它数连通域）
不出不内联 style、不用 fill 描边、不含 id 依赖、不加 padding（留白靠栅格）
导出尺寸SVG 为主；位图出 @1x/@2x/@3x PNG，命名 -24/-48 后缀
